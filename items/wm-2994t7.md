Two defects in the dashboard itself, found 2026-08-24 by reading its JSON
(uid openroad-sfvsds-fullhist, version 1, last edited 2026-07-03). Separate from the data
problem in [[wm-vzrdrm]] — these are wrong even after the backfill.

1. THE DROPOUT PANELS SHOW PROSPER. All three panels under "Dropout Analysis" (ids 35, 36, 37)
   query `${database}.gold.positions_autofilled_daily WHERE platform = 'prosper'`, hardcoded.
   On a board titled OpenRoad, three panels are quietly reporting another platform. Fix is to
   change the literal to 'openroad' — the data exists: PROD.GOLD.POSITIONS_AUTOFILLED_DAILY has
   openroad through 2026-08-24, 1132 rows.

2. THE DEFAULT DATABASE IS A DEAD COPY. The `database` template variable defaults to
   DEV_ABHISHEK, where openroad stops at as_of 2026-08-09 (last write 2026-08-11). Anyone who
   opens the board without ?var-database=PROD in the URL sees data two weeks stale and gets no
   warning. Either flip the default to PROD or refresh the dev copy.

3. WORTH A DECISION, not obviously a bug: the board is titled "Full History Analysis" and its
   saved time range starts 2023-07-01, but POSITIONS_COMPARISON_DAILY holds nothing before
   2026-03-21 in either database — for any platform. The narrative text panels describe a
   2024-11-21 issuance-backfill cliff that no longer has rows behind it. Either the pre-March
   history needs rebuilding or the title and range should be honest about the window.
